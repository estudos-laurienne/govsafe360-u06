Não usar @README.md isolado. Primeiro o prompt de leitura do Moodle, depois planejamento, autorização, execução e evidências.

## Portões de aprovação
- Instalação e autenticação: solicitar aprovação, utilizar apenas canais oficiais.
- Git init/commit: explicar antes. Não sobrescrever .git existente.
- GitHub: revisar arquivos e .gitignore antes do primeiro push.
- Vercel: conferir diretório public e pedir autorização de publicação.
- Playwright: não presumir ferramentas nativas, instalar somente com autorização.
- Alterações: conferir git status, git diff, testes e caminhos de rollback.
